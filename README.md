## 几个容易踩的坑

**流量按双向算。** 套餐写的 1TB、2TB 都是上传加下载合计，不是单向。TikTok 直播推流是持续上传，2TB 双向意味着实际上传额度大概是标称的一半。

**超量限速不停机。** 多个套餐写“5 Mbps speed limit for excess traffic”，流量跑完限速到 5Mbps，不额外收费也不停机。发视频够用，直播会卡。

**配置真的小。** 全系 512MB 到 1GB 内存、10GB 硬盘。跑 TikTok 环境、代理、轻量脚本没问题，跑视频转码、大型数据库、多站点建站都不够。

**热门 SKU 会缺货。** 新加坡 AUD$16.90 那档当前显示 0 Available，急着用就得换备选机房。

**“无需中转”和“带宽大”往往不能同时拿到。** 日本无需中转版 50Mbps、1.2TB；需要中转的版本 200Mbps、2TB。线路优化是用带宽和流量换的。

**支付方式。** 第三方测评提到支付宝和微信都能付，也支持信用卡与 PayPal，官网页面没有集中列出，以下单页为准。管理面板是 WHMCS 加 SolusVM，支持后台重启、重装系统、看流量、VNC。
